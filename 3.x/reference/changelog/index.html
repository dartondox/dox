    What changed in each package, newest first. This page is made from the CHANGELOG.md files in the repo when the docs are built.

    3.0.0-alpha.11

    • Version bump only, to match the other packages.

    • Version bump only, to match the other packages.

    3.0.0-alpha.9

    • New: @Inject(). Put it above a class and dox_builder adds the class to the Dox container. @Inject(singleton: false) makes a new instance each time.

    3.0.0-alpha.8

    • Version bump only, to match the other packages.

    3.0.0-alpha.7

    • Breaking: IDox, IDoxWebsocket and WebsocketEvent are removed. They were only used by dox_websocket.

    3.0.0-alpha.6

    • Version bump only, to match the other packages.

    3.0.0-alpha.5

    • New timestamps option on @DoxModel. timestamps: false turns off created_at and updated_at, like $timestamps = false in Laravel. createdAt: null or updatedAt: null turns off one of them.
    • New primaryKeyType option on @DoxModel. Use primaryKeyType: String for a UUID key. The default is int.
    • Fix: IHttpException.toResponse() now returns {"code": errorCode, "message": message} for a text message, so the client gets the errorCode. A Map message is returned as it is.

    3.0.0-alpha.4

    • Version bump only, to match the other packages.

    3.0.0-alpha.3

    • Version bump only, to match the other packages.

    3.0.0-alpha.2

    • Needs Dart 3.13 or newer.
    • All dependencies updated to their latest versions.
    • OpenAPI annotations, all optional: @Summary, @Description, @Tags, @Request, @Body, @Query, @Response, @ApiDeprecated, @ApiIgnore, @DoxController. Lower case names work too (@summary(...)), except @Response.
    • The DTO annotations (@Dto, @Length, @Email, ...) live in dox_validation. dox_core exports them.
    • IDoxRequest has no validate() and no processInputMapper() any more. Use a DTO.
    • Breaking (small): these names are exported by dox_core too. If a file also imports a package with a Request or Response class (like package:http) without a prefix, add a prefix to that import.
    • New @DoxEnv() and @EnvKey('X') for the typed env class.

    3.0.0-alpha.1

    • Version 3 of Dox. All Dox packages now share one version.
    • Needs Dart 3.6 or newer.
    • See the release notes for all main changes.

    dox_auth

    Unreleased

    • New: SessionAuthDriver keeps the login in the session, for web pages. Use Auth().attemptSession(req, credentials), Auth().loginSession(req, user) and Auth().logout(req). Login and logout give the session a new id. Needs SessionMiddleware.
    • New: AuthMiddleware(redirectTo: '/login') sends a guest to that page instead of a 401.
    • Change: the password check of attempt moved to AuthDriver.checkCredentials, so all drivers share it.

    • Version bump only, to match the other packages.

    • Version bump only, to match the other packages.

    3.0.0-alpha.9

    • Version bump only, to match the other packages.

    3.0.0-alpha.8

    • Security: a JWT secret (SecretKey) shorter than 32 bytes stops the app with an ArgumentError when APP_ENV is not development, local or test. In those envs it prints one warning line. Make a key with dox key:generate or openssl rand -hex 32.
    • Hash now comes from dox_core. dox_auth had its own copy. package:dox_auth/src/hash.dart re-exports it. No change in behaviour. dox_auth now depends on dox_core.

    3.0.0-alpha.7

    • Perf: attempt runs bcrypt in another isolate (Isolate.run). Before, each login blocked the server isolate for the whole hash.
    • Perf: the dummy hash for unknown users is made when the driver is created, in another isolate. Before, the first login paid for two hashes.
    • New: JwtAuthDriver(hashRounds: 10). Set it to the bcrypt cost of your stored hashes.
    • New: JwtAuthDriver(userCacheTtl: ...). Keeps the user of a token in memory for this time, so verifyToken does not run find(id) on every request. Off by default.
    • Security: JwtAuthDriver throws ArgumentError when the SecretKey is empty. Before, an app with no APP_KEY signed tokens with an empty key, so anyone could make a token for any user.
    • Security: attempt runs bcrypt also when no user is found, or when the user has no password. Before, an unknown email answered much faster than a wrong password, so the time told which emails have an account.

    3.0.0-alpha.6

    • Version bump only, to match the other packages.

    3.0.0-alpha.5

    • Breaking: JwtAuthDriver.expiresIn is 1 hour by default. Before, it was null, and tokens never expired.
    • New: named guards work. Use Auth(guard: 'admin') and AuthMiddleware(guard: 'admin'). Before, only defaultGuard was used.
    • A token keeps its guard name in the aud claim. A token from one guard does not work on another guard.
    • verifyToken checks the iss claim when issuer is set.
    • Breaking: AuthDriver methods get the guard name as a new parameter. AuthEngine().guard(name) replaces AuthEngine().driver and AuthEngine().provider.

    dox_builder

    3.0.0-alpha.11

    • Version bump only, to match the other packages.

    3.0.0-alpha.10

    • The app-wide files are now written to lib/generated/: lib/generated/container.g.dart, lib/generated/dtos.g.dart and lib/generated/openapi.g.dart. This keeps them out of the top of lib/. Import them from package:<app>/generated/.... Delete the old files in lib/ after you run dart run build_runner build.
    • Model part files (like user.model.g.dart) still sit next to their source file.

    3.0.0-alpha.9

    • New: lib/container.g.dart builder. It finds every @Inject() class, every class that extends Router, every class that implements DoxService and every @DoxModel in lib/. It writes registerContainer(IocContainer c), which makes each class with its constructor. Constructor parameters come from the container by type. Optional parameters that the container can not give keep their default. Required nullable ones get null.
    • The build stops with a clear message for a required parameter the container can not give, for a dependency cycle (it shows the chain, like A -> B -> A), and for an abstract or generic @Inject() class. Two classes with the same name work: every import has a prefix.
    • OpenAPI: typed routes (Route.get<C>(path, (C c) => c.method)) and Route.resource(path, ControllerClass) are read too.
    • Generates the query scopes: an extension with one method for each @Scope() method, and globalScopes for @Scope(global: true).
    • Generates the column casts: fromMap() and columnsToMap() use the cast of @Column(). bool and enum fields get a cast without cast.
    • Run dart run build_runner build to get the new code.

    3.0.0-alpha.8

    • Version bump only, to match the other packages.

    3.0.0-alpha.7

    • The generated fromMap() takes a DateTime from the driver as it is. It only parses a string.
    • New generated columnsToMap() with the columns only. convertToMap() adds the relations to it.
    • Models with no beforeGet hook get readsRowDates => true, so their rows skip the date to string step. A beforeGet hook still gets dates as strings.
    • tableColumns, preloadList, timestampsColumn and the relation matchers are const, so no new list or map is made on each call.
    • Run dart run build_runner build to get the new code.

    3.0.0-alpha.6

    • Version bump only, to match the other packages.

    3.0.0-alpha.5

    • @DoxModel(timestamps: false) makes a model without createdAt and updatedAt. createdAt: null or updatedAt: null turns off only one.
    • The primary key field has the type of @DoxModel(primaryKeyType: ...). It was always int?. The default is still int. The OpenAPI model schema uses the same type.
    • Fix: a preloaded relation with a two word name (like userInfo) was missing from toJson(). The generator looked for user_info in the preload list, but the list has userInfo.
    • Fix: the OpenAPI route scanner now puts one / between a group and a route path, like the router does.

    3.0.0-alpha.4

    • Version bump only, to match the other packages.

    3.0.0-alpha.3

    • Version bump only, to match the other packages.

    3.0.0-alpha.2

    • Needs Dart 3.13 or newer.
    • All dependencies updated to their latest versions.
    • New builder dox_builder:openapi. It writes lib/openapi.g.dart with the OpenAPI docs of the app: it reads the Route.* calls, the controllers, the @Dto classes and the models. It writes nothing when the package has no controllers.
    • DtoJsonSchema, ModelSchema and JsonSchemaReader: the JSON Schema of a @Dto class, a model or any Dart type. Other builders can use them.
    • New: the DTO generator. For each @Dto class it writes $<Name>Dto (a const DtoSchema<Name>) into the .g.dart part: plain if checks per field, the converter, fromMap, toMap and the JSON Schema. It stops the build with a clear error for a bad DTO (a field that is not final, a type that is not supported, a rule that does not fit, a bad regex, ...).
    • New builder dox_builder:dtos. It writes lib/dtos.g.dart with every DTO of the app, for AppConfig(dtos: dtos). Two DTOs with the same name stop the build.
    • DtoReader: the one place that knows DTO keys. The OpenAPI docs use the same keys as the DTO (snake_case by default, @Name, @Dto(keyCase:)).
    • OpenAPI: @Regex (was @Pattern). @Format is removed. Form requests are removed.
    • Fix: the OpenAPI route list has the full path, with the Router prefix and Route.group() prefixes. Two '/' routes in two groups now each get their docs.
    • OpenAPI path params: every positional argument that is not the request and not a DTO.
    • New: @DoxEnv() classes get _$<Class> in the .g.dart part. Each getter is read from the env once, converted to its type (String, int, double, num, bool, Uri, Duration, enum, List) and kept in a final field. A getter body is the default. A nullable getter is optional. load() throws one EnvException with every missing or bad key.

    • Needs Dart 3.6 or newer.
    • See the release notes for all main changes.
    • Works with analyzer 5 and 6.

    • Version bump only, to match the other packages.

    • Version bump only, to match the other packages.

    3.0.0-alpha.7

    • Perf: the memory driver removes expired items and expired locks in a sweep after many writes. Before, a key that was written once with a ttl and never read again stayed in memory forever.
    • Perf: the memory driver with no max_size does not reorder the map on every hit. The order is only needed for LRU.

    • Security: when CorsOptions.origins lists origins, a websocket from another origin gets 403. With no cors, or with *, any origin is still allowed.
    • Breaking: CorsOptions(origins: ['*'], credentials: true) throws an ArgumentError. Before, it sent back any origin with credentials.
    • Security: a middleware error that is not a SocketIoException sends {"message": "Internal error"} to the client and writes the real error to stderr.

    • Security: a client whose CONNECT is refused is closed after connectTimeout. Before, it could stay connected forever.

    • Security: a binary packet may have at most 10 attachments (SocketDecoder(maxAttachments: ...)). More closes the connection with a parse error. Before, a client could send 51000000-[...] before any auth and the server kept every binary frame after it in memory.
