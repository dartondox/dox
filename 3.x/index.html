    Fast backends
    in Dart

    Write in Dart. Serve with Rust.

    Dox is a web backend framework for Dart, like Laravel. Routing, an ORM, migrations, validation, auth and a CLI come in one place. It runs one isolate per CPU core and builds to a small native binary.

    Build your first API GitHub 

    Route.get('/blogs', BlogController.index); // (1)!

enum Status { active, draft }

@Dto() // (2)!
class BlogFilter {
  final Status status; // ?status=active, else 422
  const BlogFilter({required this.status});
  static const DtoSchema<BlogFilter> schema =
      $BlogFilterDto; // (3)!
}

class BlogController {
  static Future<List<Blog>> index(
    BlogFilter query, // (4)!
  ) async {
    return Blog()
        .where('status', query.status.name)
        .get(); // (5)!
  }
}
    1. A route points at a static method. No reflection, no controller registry.
    2. @Dto() marks an input class. build_runner generates the checks from the fields and their types.
    3. The generated schema. The same schema feeds the OpenAPI docs.
    4. Ask for the DTO as a parameter. Dox reads the query (or the body), checks it, and gives you a typed object. Bad input gets a 422 before your code runs.
    5. The ORM. The same code runs on Postgres, MySQL and SQLite, through native Rust drivers.

    How fast

    1.5× Bun. 2.3× Go. 7× plain Dart.

    A real route: read one row from Postgres and return JSON (GET /db). Requests per second on one CPU core, higher is better.

    req/s p99 RAM
    Doxnative server + driver 85,381fastest 5.7 ms 24 MB
    BunBun.serve + Bun.sql 57,6141.5× slower 6.1 ms 36 MB
    Gonet/http + pgx 36,7062.3× slower 14.5 ms 18 MB

    Dox 3.0.0-alpha.3 · Bun 1.4 · Go 1.27 · Dart 3.13 · Postgres 18 · 256 connections · wrk · median of 3 runsAll results

    Dox also has the lowest p99 (the slowest 1% of requests). Your code is plain Dart. The speed comes from the Rust HTTP server and the Rust database drivers that Dox uses by default. On 2 cores Dox stays ahead on the database routes. Without a database (GET /json), Bun is faster. See Performance for every route and how to run the benchmark yourself.

    You are reading the 3.x docs (alpha)

    3.0.0-alpha.x is a preview. Things can still change before the stable release.

    Run it in two minutes

    You need Dart 3.13 or newer. Nothing else: the starter project uses SQLite, so there is no database to install.

    dart pub global activate dox ^3.0.0-alpha   # install the CLI
dox create my_app                            # download the starter project
cd my_app
dart pub get
cp .env.example .env
dox s                                        # start the server

    Open a second terminal and call the first route:

    curl localhost:3000/ping

    pong

    That is a Dox app. Keep going with the tutorial: it adds a model, a database table, validation, login and a Docker image, one short step at a time.

    The CLI is not found?

    dart pub global activate puts dox in $HOME/.pub-cache/bin. Add that folder to your PATH. See Installation.

    What you get

    • Fast by default

      A Rust HTTP server, one isolate per CPU core and streamed bodies. dox build makes one native binary. See Performance.

    • ORM and query builder

      Models, relations, migrations and transactions for Postgres, MySQL/MariaDB and SQLite, with native Rust drivers. See Database.

    • Typed validation

      Write a @Dto class. Dox checks the input and gives your controller a typed object. See Validation.

    • OpenAPI

      OpenAPI 3.1 docs and a Scalar docs page, made from your routes and DTOs. See dox_openapi.

    • File storage

      Local disk and S3 behind one API, with signed URLs. See dox_storage.

    • Cache

      Memory, file and Redis cache with tags and locks. See dox_cache.

    • Real time

      WebSocket or Socket.IO, with Redis for many servers.

    • Security

      JWT authentication, CORS, encryption and hashing.

    • CLI

      Create projects, controllers, models and migrations. Run, build and migrate. See CLI reference.
