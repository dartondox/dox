# dox_core

The core of the Dox framework: HTTP server, router, requests, responses, DTO input, cache and config.

[![pub package](https://img.shields.io/pub/v/dox_core.svg)](https://pub.dev/packages/dox_core)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/dartondox/dox/blob/main/LICENSE)

Part of [Dox](https://dartondox.dev), a web backend framework for Dart, like Laravel.
Source code: [github.com/dartondox/dox](https://github.com/dartondox/dox).

## Install

The easy way is the `dox` CLI. It makes a full starter project:

```bash
dart pub global activate dox ^3.0.0-alpha
dox create my_app
```

To add the package to your own project:

```bash
dart pub add dox_core
```

Dox 3.x is in alpha (`3.0.0-alpha.x`). The API can still change before the stable release.

## Use it

A full app with one route:

```dart
import 'package:dox_core/dox_core.dart';

class ApiRouter extends Router {
  @override
  String get prefix => 'api';

  @override
  void register() {
    Route.get('/ping', (DoxRequest req) => 'pong'); // GET /api/ping
  }
}

void main() async {
  Dox().initialize(AppConfig(
    appKey: Env.get('APP_KEY'), // read from .env
    serverPort: 3000,
    routers: <Router>[ApiRouter()],
  ));
  await Dox().startServer();
}
```

Run it with `dart run bin/server.dart`, then call `curl localhost:3000/api/ping`.

A controller can ask for a typed, checked input class (a DTO):

```dart
@Dto()
class CreateBlog {
  @Length(min: 3, max: 200)
  final String title;

  const CreateBlog({required this.title});
  static const DtoSchema<CreateBlog> schema = $CreateBlogDto;
}

class BlogController {
  Future<Blog> store(CreateBlog body) async { ... } // bad input gets 422
}
```

The DTO code is generated by `dox_builder` (`dart run build_runner build`).

## Features

- One isolate per CPU core. All isolates serve the same port.
- A native HTTP server (`dox_http_native`): Rust parses HTTP and speaks WebSocket, your code stays in Dart.
- Router with groups, middleware, typed path params and resource routes.
- DTO input: Dox reads the body or query, checks it, and answers `422` with all errors.
- `Cache()` (from `dox_cache`). For `Storage()`, add the `dox_storage` package.
- OpenAPI docs at `/docs` (from `dox_openapi`). Off in production by default.
- Socket.IO on the same port: add the `dox_socketio` package.
- Typed env class, CORS, cookies, hashing and encryption.
